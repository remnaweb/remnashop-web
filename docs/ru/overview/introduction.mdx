title: "Что это"
description: "Веб-кабинет и Telegram Mini App для бота RemnaShop"
---

**remnashop-web** — отдельная веб-морда для уже установленного [RemnaShop](https://remnashop.mintlify.app/docs/ru/overview/introduction).

Пользователь нажимает **«Личный кабинет»** в боте и сразу попадает в кабинет: подписка, тарифы, оплата, устройства, промокод, рефералка.

Код бота (`/opt/remnashop`) менять не нужно. Тарифы, цены и платёжки берутся из админки RemnaShop.
