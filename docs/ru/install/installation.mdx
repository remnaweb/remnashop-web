Веб-кабинет для уже установленного [RemnaShop](https://remnashop.mintlify.app/docs/ru/install/installation). Код бота (`/opt/remnashop`) менять не нужно.

После установки пользователь нажимает **«Личный кабинет»** в боте и сразу попадает в кабинет: подписка, тарифы, оплата, устройства, промокод.

<Warning>
  Сначала должен работать RemnaShop (контейнеры `remnashop` и `remnashop-db`). Mini App Telegram работает только по HTTPS и только с домена, не с IP и не с HTTP.
</Warning>

## Get started

<Steps>
  <Step title="Install">
    Установите Docker, если его ещё нет:

    ```bash
    sudo curl -fsSL https://get.docker.com | sh
    ```

    Одна команда ставит кабинет: находит сеть бота, собирает контейнер, добавляет HTTPS в Caddy и включает кнопку **«Личный кабинет»**.

    ```bash
    git clone https://github.com/remnaweb/remnashop-web.git /opt/remnashop-web
    cd /opt/remnashop-web
    cp install.conf.example install.conf
    nano install.conf
    ```

    Впиши свой домен (без `https://`), не example.com:

    ```bash
    DOMAIN=lk.твой-домен.ru
    ```

    Остальные строки можно не трогать. Затем:

    ```bash
    chmod +x install.sh
    ./install.sh
    ```

    Username бота скрипт берёт из токена RemnaShop. Код `/opt/remnashop` не меняется, только `.env` бота (`WEB_ENABLED`, `WEB_CABINET_URL`).
  </Step>

  <Step title="Configure">
    Вход через Telegram работает сразу. Письма (регистрация / сброс пароля) — по желанию:

    ```bash
    cd /opt/remnashop-web
    ./deploy.sh configure
    ```

    Выберите Resend или SMTP. Без этого пункт «Пропустить» — нормально.

    Resend:

    ```env
    MAIL_PROVIDER=resend
    MAIL_FROM=noreply@yourdomain.com
    RESEND_API_KEY=re_xxxxxxxx
    RESEND_FROM=My VPN <noreply@yourdomain.com>
    ```

    SMTP:

    ```env
    MAIL_PROVIDER=smtp
    MAIL_FROM=noreply@yourdomain.com
    SMTP_HOST=smtp.yourdomain.com
    SMTP_PORT=587
    SMTP_SECURE=false
    SMTP_USER=noreply@yourdomain.com
    SMTP_PASSWORD=change_me
    ```

    Домен в `MAIL_FROM` должен быть вашим. Для Resend подтвердите домен (DKIM / SPF). После смены `NEXT_PUBLIC_*`: `./deploy.sh update`.
  </Step>

  <Step title="Run it">
    Проверка на сервере — `200` или редирект, не `502` (домен — тот же, что в `install.conf`):

    ```bash
    curl -I http://127.0.0.1:3006/dashboard
    curl -I https://ТВОЙ-ДОМЕН/dashboard
    ```

    В [@BotFather](https://t.me/BotFather): `/mybots` → ваш бот → **Bot Settings** → **Configure Mini App**.

    * URL: `https://ТВОЙ-ДОМЕН/dashboard`
    * Domain: `ТВОЙ-ДОМЕН`

    Откройте кабинет в браузере и кнопку **«Личный кабинет»** в боте.
  </Step>
</Steps>

## Переменные веб-морды

`NEXT_PUBLIC_*` попадают в сборку образа. После их смены: `./deploy.sh update`.

| Переменная | Обязательная | Описание |
| --- | :---: | --- |
| `REMNASHOP_URL` | ✅ | API бота. В Docker: `http://remnashop:5000` |
| `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME` | ✅ | Username бота без `@` |
| `NEXT_PUBLIC_BRAND_NAME` | ❌ | Название в интерфейсе и письмах |
| `NEXT_PUBLIC_SUPPORT_LINK` | ❌ | Кнопка поддержки |
| `WEB_PORT` | ❌ | Порт на хосте, по умолчанию `3006` |
| `REMNASHOP_DOCKER_NETWORK` | ❌ | Сеть бота. Часто `remnashop` или `remnawave-network` |
| `MAIL_FROM` | для писем | Адрес отправителя |
| `MAIL_PROVIDER` | ❌ | `resend` или `smtp` |
| `RESEND_API_KEY` | для Resend | Ключ с [resend.com](https://resend.com) |
| `SMTP_HOST` / `SMTP_PORT` / `SMTP_USER` / `SMTP_PASSWORD` | для SMTP | Свой почтовый сервер |
| `WEB_THEME_ADMIN_IDS` | ❌ | Telegram ID админов через запятую |

## Управление

```bash
cd /opt/remnashop-web
./install.sh
./deploy.sh ps
./deploy.sh logs
./deploy.sh restart
./deploy.sh update
```

Не запускайте `docker compose down -v`, если нужно сохранить `data/theme.json`.

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| `502` | Контейнер запущен, `reverse_proxy` смотрит на `127.0.0.1:3006` |
| Снова просит вход | `WEB_CABINET_URL` без `/dashboard`; Mini App открыт по HTTP или по IP; бот не перезапущен через `docker compose up -d` |
| Нет кнопки «Личный кабинет» | В `.env` бота `WEB_ENABLED=true` и заполнен `WEB_CABINET_URL` |
| `network ... not found` | В `.env` укажите `REMNASHOP_DOCKER_NETWORK=` имя из `docker inspect remnashop` |
| «Письма не настроены» | Задайте `RESEND_API_KEY` или `SMTP_*` |
| Ошибка оплаты | Ключи шлюза в админке RemnaShop, не в веб-морде |
