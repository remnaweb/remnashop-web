При установке веб-морды скрипт сам включает Mini App и **убирает дубли** в боте. Подписка, устройства, инвайт и поддержка остаются в кабинете.

В главном меню бота остаются:

- **«Личный кабинет»** — Mini App (подключиться, тарифы, оплата, устройства, рефералка, помощь)
- ваши кнопки из редактора меню (соглашение, политика)
- **«Панель управления»** — только админам
- пробный период, если он включён

Скрываются: **Подключиться**, **Устройства**, **Подписка**, **Пригласить**, **Поддержка**.

`./install.sh` делает это сам. Уже стоящий бот:

```bash
cd /opt/remnashop-web
./deploy.sh patch-menu
```

<Danger>
  Патч правит файл меню **внутри контейнера** `remnashop`. После `docker compose pull` / обновления образа бота запустите `./deploy.sh patch-menu` снова.
</Danger>

## Переменные RemnaShop

В `.env` бота (`/opt/remnashop/.env`):

```env
WEB_ENABLED=true
WEB_CABINET_URL=https://ТВОЙ-ДОМЕН/dashboard
APP_ORIGINS=https://ТВОЙ-ДОМЕН
```

Затем:

```bash
cd /opt/remnashop && docker compose up -d remnashop
cd /opt/remnashop-web && ./deploy.sh patch-menu
```

## BotFather

1. [@BotFather](https://t.me/BotFather) → `/mybots` → ваш бот.
2. **Bot Settings** → **Configure Mini App**.
3. URL: `https://ТВОЙ-ДОМЕН/dashboard`.
4. Domain: `ТВОЙ-ДОМЕН` (без `https://`).
